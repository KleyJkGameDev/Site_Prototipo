---

## Visão Geral

O repositório `Site_Prototipo` reúne uma estrutura simples de front-end estático, organizada em pastas para separar:

- conteúdo visual;
- layout da página;
- recursos visuais;
- organização da estrutura do projeto.

A estrutura sugere um protótipo de página ou landing page, com foco em interface visual, design e apresentação.
